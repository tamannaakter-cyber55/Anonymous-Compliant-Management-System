
# Anonymous Complaint Management System

## Project Overview
The Anonymous Complaint Management System is a Java-based application developed using Object-Oriented Programming (OOP) principles. It allows students to submit complaints anonymously, track their progress using unique tracking codes, and receive responses from relevant staff members.

The system aims to promote student privacy, accountability, and efficient complaint management within a university.

## Features
- Anonymous complaint submission
- Unique complaint tracking codes
- Multiple complaint categories
- Priority selection (Low, Medium, High)
- Complaint status tracking
- Staff authentication and category-based access
- Staff replies and status updates
- Admin dashboard with basic statistics

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Java Collections Framework
- Exception Handling

## User Roles
1. Student: Submit and track complaints anonymously.
2. Staff: View assigned complaints, update statuses, and respond.
3. Admin: Manage and monitor complaints through administrative features.

## How to Run

1. Clone the repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project directory.

3. Compile the Java program:
   ```bash
   javac CMS.java
   ```

4. Run the application:
   ```bash
   java CMS
   ```
